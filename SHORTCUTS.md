# Shortcuts

A short list to keep open while you work. Start with the first two of each section. The rest will become habits over the first week.

## PyCharm

These are PyCharm's default keyboard shortcuts. On a Mac, if an F-key changes the volume or brightness, hold **fn** with it.

### Terminal and windows

| What | Mac | Windows / Linux |
|---|---|---|
| Open the terminal, or jump to it | ⌥F12 | Alt+F12 |
| Back to the editor, terminal stays open | Esc | Esc |
| Hide the terminal and go back to the editor | ⇧Esc | Shift+Esc |
| New terminal tab | ⌘T | Ctrl+Shift+T |
| Hide every panel except the editor (press again to bring them back) | ⇧⌘F12 | Ctrl+Shift+F12 |

### Running code

| What | Mac | Windows / Linux |
|---|---|---|
| Run the file open in the editor | ⌃⇧R | Ctrl+Shift+F10 |
| Run the last thing again | ⌃R | Shift+F10 |
| Debug the file open in the editor | ⌃⇧D | Ctrl+Shift+F9 |
| Stop the running program | ⌘F2 | Ctrl+F2 |

### Editing

| What | Mac | Windows / Linux |
|---|---|---|
| Show fixes for the code under the cursor | ⌥↩ | Alt+Enter |
| Complete the word you're typing | ⌃Space | Ctrl+Space |
| Comment or uncomment the line | ⌘/ | Ctrl+/ |
| Duplicate the line | ⌘D | Ctrl+D |
| Delete the line | ⌘⌫ | Ctrl+Y |
| Move the line up or down | ⌥⇧↑ / ⌥⇧↓ | Alt+Shift+↑ / Alt+Shift+↓ |
| Tidy up the file's formatting | ⌥⌘L | Ctrl+Alt+L |
| Undo / redo | ⌘Z / ⌘⇧Z | Ctrl+Z / Ctrl+Shift+Z |

### Finding things

| What | Mac | Windows / Linux |
|---|---|---|
| Search for anything: files, classes, settings | ⇧ twice | Shift twice |
| Open a file by name | ⌘⇧O | Ctrl+Shift+N |
| Recently opened files | ⌘E | Ctrl+E |
| Jump to where a function or variable is defined | ⌘B | Ctrl+B |
| Search the text of every file | ⌘⇧F | Ctrl+Shift+F |
| Show or hide the project file list | ⌘1 | Alt+1 |
| Find any menu command by name | ⌘⇧A | Ctrl+Shift+A |
| Settings | ⌘, | Ctrl+Alt+S |

Forgot a shortcut? Press ⌘⇧A (Ctrl+Shift+A), type what you want to do, and PyCharm shows the command with its shortcut next to it.

## Learning path

The commands you'll type most, in PyCharm's terminal. The full list is in [README.md](README.md#all-commands).

| Command | What it does |
|---|---|
| `l session <id> --hours 2` | Pick today's chapter and start its log entry. Leave out the id for the same chapter as last time. |
| `s` | Get your mentor's feedback and submit your progress. First and last thing every session. |
| `l ex 2-1 "Simple Message"` | Create a file for the next exercise |
| `l done 2-1` | Tick off an exercise |
| `l note "..."` | Write down something you learned |
| `l ask "..."` | Ask your mentor something, after trying for 30 minutes |
| `l park "..."` | Set something aside to finish later |
| `l next` | Chapter finished and Retro filled in: close it and move to the next one |
| `l status` | Where you are across every chapter |
