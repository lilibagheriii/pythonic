Beginner → mid-level Python developer, no CS degree

Python Career Roadmap

Yes, the program can get someone without a CS degree into the job market. It builds the skills. Three additions help those skills get past hiring filters and interviews.

It produces evidence

Junior hiring runs on proof: deployed projects, tests, Git history, and a walkthrough of your own code. Every phase ends in one of those, and the daily commits in the learning repo are evidence too.

Phase 2 is real CS

Composing Programs is the text of Berkeley's CS 61A. It covers the core ideas of a first-year computer science course: abstraction, recursion, efficiency, interpreters, and SQL.

Where a degree still counts

Some large employers and most visa sponsorship screen on degrees. Referrals and internal moves skip that screen, so the student's new full-time job may be the best way in.

Titles follow experience

Studying alone doesn't make anyone mid-level. That title usually comes 2–3 years into a developer job. The plan gets the first job and makes those years count.

Add these to the program

Algorithms and data structures

Months 5–10, alongside Fluent Python

Grokking Algorithms, 2nd ed. (Aditya Bhargava), plus 2–3 practice problems a week, from easy to medium. Most developer interviews include a coding problem, and Phase 2 only starts this topic.

Tools of the job

Months 6–9, used in the capstone

The Linux Command Line (William Shotts, free online), Docker basics, and how HTTP works. These come up from the first day of any developer job.

Job search

From month 4 until the first developer job

Polished project READMEs, a résumé that leads with projects, LinkedIn, one meetup a month, and asking for referrals. Monthly mock interviews with the mentor start in month 7.

pandas, for the data route

Months 3–5, only if aiming at role 2 as a data analyst

Python for Data Analysis, 3rd ed. (Wes McKinney, free online). Analyst interviews expect pandas and Jupyter on top of SQL.
